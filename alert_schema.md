# IDS Alert Schema

Each alert generated by the IDS uses this JSON schema.

| Field | Type | Meaning | Example |
|---|---|---|---|
| `alert_id` | string | Unique alert identifier | `ALT-0001` |
| `timestamp` | string | UTC timestamp when the alert was created, in ISO 8601 format | `2026-06-01T10:15:12Z` |
| `device_id` | string | Originating device identifier | `HRM001` |
| `alert_type` | string | Detection category | `Data Injection` |
| `severity` | string | Alert urgency level | `HIGH` |
| `anomaly_score` | number | Confidence / anomaly severity score between 0 and 1 | `0.94` |
| `description` | string | Human-readable explanation of the alert | `Heart rate value exceeds normal range` |
| `recommended_action` | string | Suggested next step for operators or automation | `Verify sensor integrity` |
